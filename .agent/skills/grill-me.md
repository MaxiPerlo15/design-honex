# Skill: grill-me

## Purpose

Use this skill whenever a request is incomplete, ambiguous, or lacks enough information for implementation.

The objective is to achieve a shared understanding of the problem before creating a PRD, generating designs, or writing code.

Do not assume requirements.

Ask questions until the design intent is sufficiently clear.

---

## When To Use

Use this skill when requests contain phrases such as:

* Build a landing page.
* Improve the design.
* Make it more modern.
* Create a portfolio.
* Add a section.
* Redesign the homepage.
* Make the UI better.
* Create a website for a client.
* Generate a new page.

If implementation details are unclear, stop and grill first.

---

## Interview Rules

Ask only the highest-leverage questions.

Avoid asking everything at once.

Prioritize questions that will significantly affect:

* Layout
* Content
* Branding
* User experience
* Conversion strategy

Prefer iterative questioning.

---

## Discovery Framework

### 1. Business Goal

Determine the primary purpose of the website.

Questions:

* What is the main objective of the site?
* What action should visitors take?
* What defines success?

Examples:

* Generate leads.
* Showcase work.
* Build authority.
* Sell a service.
* Book meetings.

---

### 2. Target Audience

Understand who the website is for.

Questions:

* Who is the ideal client?
* Individuals or businesses?
* Local or international?
* Small businesses or larger companies?
* Technical or non-technical audience?

---

### 3. Brand Positioning

Understand how the brand should be perceived.

Questions:

* Premium or approachable?
* Minimalist or expressive?
* Corporate or creative?
* Modern or timeless?
* Bold or elegant?

---

### 4. Visual Direction

Determine visual style.

Questions:

* Preferred color palette?
* Light mode or dark mode?
* Existing logo?
* Existing brand identity?
* Websites used as inspiration?
* Design styles to avoid?

---

### 5. Content Discovery

Determine available content.

Questions:

* What sections are required?
* Services?
* Portfolio?
* Testimonials?
* About section?
* Contact information?
* Existing copywriting?

---

### 6. Conversion Strategy

Determine the primary CTA.

Questions:

* WhatsApp?
* Contact form?
* Email?
* Calendly?
* Instagram?
* Phone call?

Only one CTA should be primary.

---

### 7. Technical Constraints

Determine implementation constraints.

Questions:

* Single page or multiple pages?
* Need animations?
* Need SEO basics?
* Need CMS?
* Need multilingual support?
* Deadline?

---

## Synthesis Phase

Once sufficient information has been gathered, stop asking questions.

Generate a structured summary.

Use the following format:

# Shared Design Concept

## Project

Brief project description.

## Goal

Primary business objective.

## Audience

Target audience.

## Brand Positioning

Desired perception.

## Visual Direction

Color, typography, layout and aesthetic direction.

## Required Sections

List all required sections.

## Primary CTA

Main conversion action.

## Constraints

Technical and business constraints.

## Out of Scope

Explicitly define what will not be built.

---

## Success Criteria

The skill is complete when:

* The project goal is clear.
* The audience is clear.
* The visual direction is clear.
* Required sections are defined.
* The CTA is defined.
* Constraints are known.

Only then should a PRD be created.
